How to label (read this first, about 5 minutes)

Each screen shows one number from the agent's paper (highlighted), the sentence or table cell it sits in, and up to three places in the agent's own result files where the same value appears. Pick one answer:

1 Traceable
A file entry shows this value for the same thing the paper is talking about: same experiment, same metric, same model or setting. Rounding is fine (0.13425 → 0.134; 0.0804 → 8.04%).
2 Wrong source
The value appears, but every entry shown is about something else: a different model, run, dataset, metric (e.g. std instead of mean), or an unrelated line such as a timer or a training-loss print.
3 Not found
No entry is shown, or nothing shown is even close to the right kind of thing.
4 Not a claim
The number is a setting, not a result: a grid or sweep value, a tolerance, a threshold, a confidence level (95%), a chosen parameter, or a value simply computed from settings. Also use 4 for citations, equation numbers and formatting.

Examples

  • Paper: "unseen IC families at 0.4583" (multi-family model). File: aggregate/summary.json → multi-family structured heldout_family rel mean = 0.45828. Same thing → 1.
  • Paper: "matches … to within 0.02 relative L2 (0.045 vs. 0.026 on reaction–diffusion)". Only entries: cdr_raw_s2.json → ablation_constant unseen_ic_param rel_l2_std = 0.0453 — a standard deviation from a different experiment. → 2.
  • Paper: "the grid is ε ∈ {0.125, 0.1875, 0.25}". File: method_plan.json → eps_grid = 0.1875. It is a setting → 4.

Work on your own and go with your first careful judgement; there is no time pressure and no right answer we are hoping for. Keys: 1–4 answer and move on, ←/→ step, n jumps to the next unanswered one. "Raw data" marks entries from large tables, which are rarely the source of a reported summary. Your answers save automatically.
